# nimbls — Standard marketing sharing guide

Updated September 23, 2026. Development names and planned-capability labels must remain visible when materials are reused.

## Reusable product introduction

nimbls is an Agent workspace for running tasks, retaining useful context and producing inspectable results. We are starting with network operations: daily checks, site knowledge and evidence-backed investigation. Ask nimbls is the main assistant inside the workspace. NIMBL is the separate network management system used by planned network workflows.

## Current development scope

The reviewed development build supports saved Agents, scoped file tools, text outputs, retained execution records, explicit preferences and optional evaluations. Selected real-provider checks are documented in the development evidence. Full Agent acceptance and the complete network workflow remain unfinished; this is not a packaged release.

## Choose the material for the conversation

- Product introduction: network architecture and Ask nimbls workflow diagrams.
- Customer scenario: daily network journey and default-Agent feature cards; retain planned labels.
- Capability evolution: seven-milestone evolution diagram; use the interactive roadmap for dated planning scenarios.
- Current demonstration: actual development screenshots together with their dated evidence and limits.
- Proposal preparation: feature cards, sales/demo script and sample report in Resources. The demo script describes a planned journey; the report is a template.

## Formats and sharing

Use PNG in slides, SVG for editing and Markdown for reusable copy. The complete marketing ZIP includes the browsable website and supporting assets; the Visual Library ZIP contains visuals and notes. Send the Visual Library page for an online preview, or share a downloaded ZIP for offline reuse. Preserve captions distinguishing planned concepts, historical reconstructions and actual development captures. nimbls and Ask nimbls are provisional names; the feature icon is not a final corporate logo.
